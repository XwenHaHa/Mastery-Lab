## 1. 已完成内容

### 1.1 学习历史记录

- 每次进入教室记录一条学习活动：课程、知识点、会话、开始/结束、有效时长、阶段、结果、尝试与提示次数。
- 支持最近记录、按课程/知识点/时间筛选、分页、详情查看。
- 详情包含阶段事件、问答与评价、当次错误与补讲、最终总结。
- 时间来自心跳累计，不是页面打开到关闭的墙钟差。

### 1.2 断点续学

- 保存课程/章节/知识点/会话、教学阶段与阶段状态、历史对话、当前问题、尝试与提示、草稿、输入模式。
- 刷新、关闭教室、关闭浏览器、本地服务重启后均可恢复。
- 等待回答时恢复同一问题与草稿，不重新生成；VERIFY 已通过不重复验证。
- 恢复不重复创建会话；用户主动「重新学习」才开启新轮次，旧证据保留。

### 1.3 知识掌握档案

- 6 态：未接触、已接触、理解中、引导练习、独立完成、需要复习。
- 只由教学状态机的真实事件推导，写 `mastery_history`。
- 一次答对不会直接判定长期掌握；独立验证通过且未使用验证提示才是 `INDEPENDENT`。
- 课程详情与学习档案展示掌握状态与状态变化原因。

### 1.4 错题与薄弱点

- 记录 CHECK/PAIR 错误与 VERIFY 失败；自由提问与 `UNCLEAR` 不记错题。
- 相同知识点 + 阶段 + 相同错误归并，保留每次发生的完整上下文。
- 支持课程/知识点/错误类型/状态筛选、完整详情、标记已理解、重新打开、重新练习。
- 重新练习只打开对应教室，不自动清空错题或伪造掌握。

### 1.5 学习档案页与报告

- `/learning`：总览、课程进度、掌握分布、按课程/章节的掌握明细、最近历史、错题入口、本周报告。
- `/learning/mistakes`：错题列表、筛选、详情抽屉、处理状态、重新练习。
- 概览页增加「继续学习」与真实学习统计。
- 报告包含本周时长、涉及/完成知识点、主要薄弱点、最近进展、课程维度进度。

## 5. 学习时间统计规则

1. 进入教室开始活动；同一会话 15 分钟内复用，超过则关闭旧活动并新建。
2. 前端每 30 秒上报增量；仅在页面可见且最近 5 分钟有指针/键盘/滚动操作时累计。
3. 页面隐藏立即上报一次并停止；重新可见后重新计时。
4. 服务端单次最多接受 120 秒，且不超过「距上次心跳 + 5 秒」。
5. 切换知识点、离开教室、关闭页面结束活动；VERIFY 通过活动记 `completed`。
6. 后端启动关闭空闲活动，`ended_at` 取最后心跳时间；离线时间不进入 `active_seconds`。
7. 学习档案与历史只汇总 `active_seconds`，不使用开始/结束墙钟差。

## 6. 掌握状态更新规则

| 状态 | 触发 |
| --- | --- |
| `NOT_STARTED` | 默认，无证据 |
| `INTRODUCED` | TEACH / DEMO |
| `UNDERSTANDING` | CHECK 中或未稳定通过 |
| `GUIDED_PRACTICE` | CHECK 正确后进入 PAIR，或 PAIR 中 |
| `INDEPENDENT` | VERIFY 通过且验证未使用提示 |
| `NEEDS_REVIEW` | VERIFY 失败/需复习，或待复习状态再次出错 |

- 每次变化写 `mastery_history`，含前一状态、后一状态、原因、阶段、评价、尝试/提示次数。
- AI 文本不能直接改状态；状态只由教学状态机与评价触发。
- `INDEPENDENT` 不会因一次模糊回答降级；明确失败进入 `NEEDS_REVIEW`。
- 重新学习保留旧历史与旧状态，后续证据可再次改变状态。

## 10. P2 开发建议

1. **Monaco 编辑器**：在教室右侧加入可折叠编辑器，保留当前三栏教学结构；`learning_breakpoints` 增加编辑器内容、
   光标位置、当前文件与运行结果引用，继续使用 `client_seq`。
2. **运行时沙箱**：`runtime/runner` 独立进程，临时目录、超时、进程树终止、内存/子进程限制、默认禁网；
   只回传 stdout/stderr/退出码/耗时，不回传环境变量与密钥。
3. **运行结果进入教学上下文**：把最近一次运行的结构化结果作为证据，限制长度，不把整个终端历史发给模型。
4. **VERIFY 与代码结合**：预测输出、改参数、迁移小练习；仍然坚持「讲解 → 演示 → 一起写 → 独立写」。
5. **断点扩展**：保存编辑器内容、运行结果与待完成任务；恢复时区分「代码草稿」与「对话草稿」。
6. **测试**：为 Monaco 与执行沙箱增加前端测试、后端沙箱安全测试、端到端运行失败/超时/无网络场景。
7. **不改动现有口径**：学习活动、掌握状态、错题与报告继续复用 P1.5 表；P2 只新增代码与运行证据字段。
