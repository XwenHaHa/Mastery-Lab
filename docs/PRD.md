# Mastery Lab PRD

- 版本：P0 + P1.1 + P1.2 + P1.3 / v0.1.0
- 状态：基础设施、教材导入、课程管理与 AI 学习教室已实现；工作区有教学状态机代码，未在本轮 P0 验收
- 目标系统：Windows 10 / 11，浏览器访问本机服务

## 1. 产品定位

Mastery Lab 是一个本地优先的 **AI 互动技术学习平台**。用户导入自己的技术教材（Markdown、PDF），
AI 扮演耐心的技术老师：按知识点讲解、演示最小案例、一次只问一个问题、陪用户在内置编辑器里写代码并运行，
直到用户能独立完成与迁移。

明确不是：
- 不是通用 AI 聊天客户端（没有自由对话工作台）。
- 不是自动出题 / 判分系统。
- 不是云端 SaaS（P0 无账号、无服务端数据库、无遥测）。

## 2. 用户与场景

| 用户 | 场景 | 当前是否可用 |
| --- | --- | --- |
| 想系统学一门技术的自学者 | 导入自己的 Markdown 教程，让 AI 按章节逐步带学 | 可导入、维护目录、手工标记状态，进入知识点教室接受 AI 讲解 |
| 需要被盯着写代码的初学者 | 需要「先讲、再演示、再陪写、再验证」的节奏 | 未实现（P1.3 / P2） |
| 想复用已有课程材料的人 | 教材原文不改写，生成学习路径 | 已可导入原文、生成并维护章节/知识点目录 |

## 3. 教学原则（后续所有功能必须遵守）

1. 老师先讲解，不在一开始要求用户写代码。
2. 先演示完整最小案例，再逐步带写。
3. 每次只学一个知识点。
4. 一次只提一个互动问题。
5. 用户在内置编辑器中编写代码。
6. AI 依据真实代码与真实运行结果指导。
7. 逐步撤除提示，最终验证能否独立实现。
8. 记录学习进度、错误与掌握程度。

> P0 只负责把这些原则"能落地"的地基（本地服务、数据库、模型接入、界面骨架）做好，
> 不实现其中任何一条教学行为。

## 5. 功能需求（P0 已实现部分）

### 5.1 应用外壳
- 左侧固定导航（工作台 / 配置两组），顶部状态栏显示当前页、本地运行标识、API 文档入口、主题切换。
- 默认深色主题，可切浅色或跟随系统，选择记在 `localStorage`。
- 1440×900 以上为设计目标；窄窗口下表格横向滚动，不做移动端适配。

### 5.2 概览页
- 三项关键状态：模型配置数量、默认模型、后端服务状态（数据来自 `/api/v1/health`）。
- 学习流程 5 步以「P1 / P2」标签标明未实现，不可点击。
- 运行环境表：API 地址、前缀、数据库路径、密钥保护方式、Python 版本、平台。
- P0 交付清单，勾选项来自实际健康检查结果，未完成项（教学能力）保持未勾选。

### 5.3 模型配置页
- 列表：名称、模型名、接口地址、密钥掩码 + 加密方案、最近一次测试结果与时间、操作。
- 新建 / 编辑（弹窗表单）：配置名称、Base URL、模型名称、API Key、是否默认。
- 两个测试入口：列表行内「测试」（用库中密钥）、弹窗内「测试连接」（可用未保存的表单值）。
- 删除需二次确认；删除当前默认配置后自动把剩余的第一条设为默认。
- 同一时刻只有一个默认配置；名称唯一。

### 5.4 设置页
- 外观：深色 / 浅色 / 跟随系统。
- 本地数据：数据目录、数据库文件、上传目录、密钥保护方式（只读展示）。
- 服务：后端状态、API/前端地址、Swagger 入口。
- 关于：版本、当前阶段、技术栈、运行环境。

## 6. 非功能需求

| 维度 | 要求 | P0 实现 |
| --- | --- | --- |
| 密钥安全 | 明文不返回浏览器、不落日志、不硬编码前端 | Windows DPAPI 加密入库，响应只给固定掩码，访问日志不记录请求体 |
| 离线可用性 | 除模型请求外不依赖外网 | 前端无外部 CDN/字体，构建产物本地 |
| 数据主权 | 记录默认存本机，无平台遥测 | `data/` 目录；P1.3 生成时当前教材节选和有限历史发送至用户配置的模型 |
| 启动健壮性 | 端口冲突、依赖缺失要给出明确提示 | 脚本统一检查端口与依赖，失败打印日志尾部 |
| 可维护性 | 前后端分层清晰 | 路由 / 服务 / schema / ORM 分层，见 `ARCHITECTURE.md` |

### P1.3 已实现能力

- 三栏教程式布局：248px 课程目录、教学正文、可收起的信息面板；宽屏优先，窄屏目录遮罩与浮层。

- 不自动增加掌握度、不跳知识点、不执行代码。一次最多问一个问题是提示词约束，不是本阶段的硬性结构校验。

### 8.3 功能需求

**课程中心（`/courses`）**

- 列表展示：课程名、简介、图标或教材类型、教材来源与大小、章节数/知识点数、学习进度、最近学习时间、创建时间。
- 搜索：按课程名、简介、教材文件名（大小写不敏感），无结果给出明确空状态。
- 排序：最近学习 / 创建时间 / 最近更新。
- 操作：继续学习、编辑（名称、简介、图标，并展示原始教材信息）、删除（二次确认，说明会一起删除的内容）。
- 空状态：明确指向「导入教材」。

**课程详情（`/courses/{id}`）**

- 课程基本信息 + 学习进度概览（加权进度、四态计数、最近学习的知识点）。
- 章节树：可展开折叠，显示每章知识点数与章节进度。
- 章节管理：新增、改名、改简介、删除（二次确认）、上移/下移，顺序持久化。
- 知识点管理：新增、改名、改简介、改正文、删除（二次确认）、上移/下移。
- 知识点阅读：Markdown 正文渲染、所属章节面包屑、上一个/下一个。
- 学习状态：四态手工切换，切换后进度与计数立即更新。

### 8.4 学习状态与进度（产品口径）

| 状态 | 含义 | 进度权重 |
| --- | --- | --- |
| 未学习 `not_started` | 默认状态 | 0 |
| 学习中 `in_progress` | 正在读/练，未完成 | 0.4 |
| 待复习 `review` | 学过但需要回看 | 0.7 |
| 已完成 `completed` | 用户确认掌握 | 1 |

`进度 = round(Σ 权重 / 知识点总数 × 100)`，总数为 0 时为 0；章节进度同公式。
掌握度（0–5）本阶段不写，界面也不展示未经证据支撑的掌握度。
