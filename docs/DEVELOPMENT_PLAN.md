### 3.1 P1.1 交付内容（细节见 `docs/ARCHITECTURE.md` 第 8 节）

- 上传：拖拽/选择、20 MB 上限、扩展名白名单、上传进度；空文件/损坏文本/假 PDF/不支持类型都有明确提示。
- 解析：Markdown 标题层级 → 课程/章节/知识点，代码围栏保留语言标识；PDF 抽取文本层 + 启发式标题，扫描件明确拒绝。
- 结构预览：课程名、章节名、知识点名可改，可删除、上下移动、添加；确认后才创建正式课程。
- 数据：`courses` / `chapters` / `knowledge_points` 三张表；v1→v2 为纯新增，P0 的模型配置数据未受影响。

### 3.2 P1.2 交付内容（本轮，细节见 `docs/ARCHITECTURE.md` 第 9 节）

- **课程中心**：搜索（名称/简介/教材名）、三种排序、图标与简介编辑、原始教材信息、删除二次确认、空状态导入入口。
- **课程详情**：进度概览（加权进度 + 四态计数 + 最近学习）、可折叠章节树、左目录 + 右阅读面板。
- **章节管理**：新增、改名、改简介、删除（级联知识点）、上移/下移，顺序持久化（全量 ID 排列校验）。
- **知识点管理**：新增、改名、改简介、改正文、删除、上移/下移；正文支持 Markdown 渲染与编辑预览。
- **学习状态**：四态（未学习 / 学习中 / 待复习 / 已完成）手工切换，进度与统计立即重算并落库。
- **数据**：v2→v3 只加列（`courses.icon`、`courses.last_studied_at`、`knowledge_points.last_studied_at`）
  + 状态归一（`learning`→`in_progress`、`mastered`→`completed`），旧数据不丢。
- **验证**：后端 52 项真实 HTTP + SQLite 断言、Playwright 17 步 UI 流程、14 张实机截图。

### 3.4 P1.4 教学状态机（已完成）

- 在会话上引入版本化阶段、阶段状态、修订号与事件，不把阶段塞进自然语言历史。
- TEACH → DEMO → CHECK → PAIR（两个小步）→ VERIFY → NEXT；CHECK 错误回 TEACH，VERIFY 失败回 PAIR。
- 后端保存当前问题与尝试/提示次数，`WAITING_USER` 时只允许回答；一次最多一个待答问题。
- 结构化评价 JSON + 证据引用；泛化「我懂了」被降级为 `UNCLEAR`。
- 评价、阶段推进与完成状态在同一事务提交；失败不留下已完成评价。
- 测试：后端 23/23；隔离浏览器流程通过。

### 3.5 P1.5 学习档案与断点续学（已完成）

- 新增 `learning_activities`、`learning_breakpoints`、`mastery_history`、`mistake_records`、
  `mistake_occurrences`、`learning_events`；知识点增加 6 态掌握字段。
- 有效时长按心跳累计：页面可见 + 最近 5 分钟有操作 + 服务端单次上限；空闲 15 分钟关闭活动。
- 断点：阶段/问题/尝试由后端同步，草稿由前端防抖保存，`client_seq` 防旧覆盖新；
  刷新、关闭浏览器、后端重启均可恢复。
- 掌握状态只由真实教学事件推导，记录变化历史；一次答对不直接判定长期掌握。
- 错题只记录真实错误，相同错误归并并保留每次发生；支持筛选、标记已理解、重新练习。
- 新增 `/learning` 学习档案页与 `/learning/mistakes` 错题页，概览页增加继续学习入口。
- 测试：后端 10/10；真实浏览器 17 项检查；旧功能 P1.3 26/26、P1.4 23/23 回归通过。

## 4. P2 计划（代码学习闭环）

1. Monaco 编辑器面板（左讲解、中编辑器、右终端的三栏布局，可折叠）。
2. 代码执行沙箱 `runtime/runner`：
   - 每次运行创建独立临时目录，只读挂载练习文件；
   - 进程超时（默认 10s）强制结束整棵进程树；
   - 通过 Job Object 限制内存与子进程数；
   - 默认禁止网络访问；
   - 只回传 stdout / stderr / 退出码 / 耗时，不回传环境变量。
3. 运行结果进入对话上下文，作为 AI 点评依据。
4. 掌握验证任务：预测输出、改参数、迁移小练习。

## 5. 风险与已知问题

| 风险 | 影响 | 当前应对 |
| --- | --- | --- |
| 沙箱安全 | 直接执行用户代码可能破坏本机 | P2 单独设计与测试，未实现前不提供运行按钮 |
| DPAPI 作用域 | 换机/换用户后密文失效 | 界面上给出明确提示，要求重填 Key |
| 无迁移框架 | 目前仅支持兼容加表/加列 | 不允许自动删库；改列前引入可回滚迁移（v4 为 baseline） |
| 进度与掌握是两个口径 | 课程进度仍含用户自评的四态；掌握状态只由教学证据推导 | 学习档案中分别展示「学习状态」与「掌握状态」，不把二者混为一个百分比 |
| 学习时长依赖前端心跳 | 前端异常退出可能少记最后 <30 秒 | 页面隐藏/退出时 keepalive 补报；服务端按最后心跳结束，不把离线时间计入 |
| 断点草稿只保存文本 | 编辑器、终端与运行结果尚不存在 | P2 引入 Monaco 后扩展断点字段，保持当前会话与阶段快照兼容 |
| Markdown 渲染能力有限 | 裸 HTML / 图片 / Mermaid 不渲染 | 公式已有 KaTeX；安全优先，不新增 Mermaid 依赖 |
| 前端包体较大 | 首屏加载稍慢（本地网络影响小） | 记录在案，后续按需引入 Element Plus |
| 端口固定 | 8000/5173 被占用时无法启动 | 脚本直接报错并提示占用进程，不静默换端口 |
| 认证缺失 | 仅适合单机单用户 | 只监听 127.0.0.1；对外分发前必须加鉴权与来源校验 |
| 模型服务限流 | 真实教学可能超时或 429 | 已验证安全错误、重试入口和取消；不自动重试导致重复付费 |
| 单 worker 限制 | 内存流登记不能跨进程共享 | 当前本机 Uvicorn 单 worker；未来多进程需独立任务存储 |

## 6. 开发约定（延续到后续阶段）

- 不虚构测试结果：没有真跑过的命令不写进文档，不声称「已验证」。
- 一次只交付可运行的增量，每个模块完成后立刻验证。
- 新增依赖必须有明确用途；能用标准库/自研小模块就不引三方库。
- 教学原则写进产品，而不是只写进提示词：状态机、单问题约束、掌握度证据都要有代码层校验。
- 数据兼容优先：改结构只做「加表 / 加列 / 值归一」，不做静默破坏性变更。
