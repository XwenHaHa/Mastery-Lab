# runtime/runner（P0 仅占位）

这里将来放 **代码执行沙箱**：在用户本机以受限方式运行学习代码，把 stdout/stderr/退出码
回传给前端终端面板。P0 不实现该能力，原因见 `docs/ARCHITECTURE.md` 的「未实现与原因」：

- 在 Windows 上安全地执行用户代码需要进程隔离、超时强杀、资源限制（Job Object）、
  网络与文件系统白名单，任何一项缺失都可能破坏用户机器；这部分需要独立设计与测试，
  不能作为「顺手写一下」的功能塞进 P0。
- P0 的验收范围是基础设施（前后端骨架、数据库、模型配置、启动脚本），
  预留本目录以避免后续再改目录结构。

P2 计划目录形态（尚未实现）：

```
runtime/runner/
├── python_runner.py     # 读取 stdin 提交的代码，在临时目录执行并回传结果
├── sandbox_policy.md    # 隔离与资源限制策略
└── requirements.txt
```

在实现之前，前端不应提供「运行代码」按钮，避免出现点不动或伪执行的界面。
